캔버스 안의 진짜 DOM

아래 판은 그림이 아닙니다. 캔버스가 텍스처 한 장으로 굽어서 휘어 그리지만, 그 안의 버튼은 눌리고 목록은 굴러가고 입력칸에는 키보드로 글자가 들어갑니다.

이 브라우저에서는 판을 그대로 보여 줍니다.

빈 곳을 끌면 판이 기울고, 버튼 위에서 누르면 버튼이 눌립니다. 두 번 누르면 각도가 돌아오고, 휠을 굴리면 목록이 움직입니다.

동작 원리

굽기

판 안의 DOM 을 SVG 한 장으로 감싸 이미지로 굽고, GPU 텍스처로 올립니다. 다시 굽는 건 내용이 바뀔 때뿐이라 휘는 애니메이션은 매 프레임 돌아도 가볍습니다.

되짚기

마우스가 있는 자리를 같은 셰이더로 한 번 더 그리되, 색 대신 원래 좌표를 칠합니다. 그 한 픽셀만 읽으면 손끝이 DOM 의 어디를 짚었는지 나옵니다.

넘기기

그 자리의 진짜 요소를 찾아 hover 표시를 붙이고 누릅니다. 글자칸이면 포커스를 주고, 그다음 키보드는 브라우저가 알아서 그 칸으로 보냅니다.

한계와 지원

  • 다른 도메인에서 불러온 이미지와 웹폰트는 굽는 단계에서 빠집니다. 인라인 SVG 와 그러데이션은 그대로 나옵니다.
  • 글자를 끌어서 선택하거나 캐럿을 문장 중간에 놓는 건 안 됩니다. 포커스를 준 뒤 치는 것까지가 됩니다.
  • 화면 낭독기와 탭 키는 캔버스가 아니라 뒤에 살아 있는 DOM 을 잡습니다. 접근성은 그대로 남습니다.
  • 크롬 148에서 150 사이에는 원본 API 가 오리진 트라이얼로 열려 있습니다. chrome://flags/#canvas-draw-element 를 켜면 굽는 단계 없이 매 프레임 그대로 올립니다.
